# Referencias para el próximo video de gomitas

Esta carpeta es para los **archivos originales** de las imágenes que el cliente compartió en el chat. Todavía no se copiaron ni enviaron al proveedor. No guardar claves aquí.

Guardar las imágenes localmente con estos nombres, en JPG o PNG:

- `gusanitos.jpg`: bolsa Guandy con gusanitos/tubitos azucarados.
- `sandias.jpg`: bolsa Docile con gomitas de sandía.
- `aros.jpg`: bolsa Trululu Aros.
- `ositos.jpg`: opcional, si se dispone de una fotografía concreta de los ositos.

Antes de usarlas en la API se recortará únicamente la zona con gomitas, evitando envolturas, textos y logotipos. Cuando una bolsa no muestre claramente la gomita (por ejemplo, solo una ilustración en la envoltura), es preferible añadir una fotografía del contenido fuera de la bolsa. No se presentará el dibujo del empaque como una fotografía de la gomita real.

No hay generación automática al guardar archivos. Los prompts nuevos están en `src/config/gummy-preparation.ts`, separados de la ronda pagada anterior. Primero se cotiza y se confirma el presupuesto, porque Seedance 2.5 y Sunburst devuelven tarifas variables, no una cotización fija en este momento.
